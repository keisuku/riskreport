# リスクレポート基盤

企業向けリスクエンジニアリング・レポートを作る基盤です。1つの案件データから、簡易版（初回面談用）と網羅版（拠点別・建物別）の2つのレポートを出します。

## 使い方

`index.html` をChromeまたはEdgeで開くだけで動きます。サーバーは要りません。

- `index.html` … Excelを読み書きする部品（ExcelJS）と書体をインターネットから読み込みます。
- `index.offline.html` … ExcelJSを内蔵した版です。外部の読み込みが制限された環境ではこちらを使ってください（書体は端末のものに置き換わります）。

案件データは端末（ブラウザ）の中にだけ保存され、外部には送信しません。

| 画面 | できること |
| --- | --- |
| 診断 | サンプル企業の完成した診断結果から始まります。4つの図、拠点の略図、リスク登録簿。円や行を押すと算出根拠が開きます。 |
| 簡易入力 | 約30項目。答えるたびに想定損害額と純資産に対する比率が変わります。 |
| データ | Excel様式の出力、記入済みExcelの読み込みと検証、差分の確認、画面での編集、JSONの書き出し・読み込み。 |
| 提案台帳 | 改善提案の台帳と、回答から起こした候補。 |
| レポート | A4縦のページ表示と印刷・PDF。簡易版と網羅版。 |
| AIプロンプト | 事前調査、面談記録の構造化、章別・拠点別の執筆、改善提案の起案、検証。出力を貼り付けるとレポートに入ります。 |
| 設定 | 係数表、損害の水準の呼び名、5つのデータ定義（JSON）の編集。 |

`samples/` に、アプリが出力した様式・記入済みサンプル・サンプルレポートのPDFを置いています。

## 係数について

係数表の初期値は、仕組みを動かすための**仮置き**です。統計や約款にもとづく値ではありません。御社または引受保険会社の基準に差し替えてからお使いください。サンプル企業の会社名・数値・出典はすべて架空です。

## 構成

```
src/defs/   データ定義（コードではなくデータで持つ5つ）
  questions.json     質問マスタ（Excel様式・画面・レポートはここから生成）
  risks.json         リスク辞書、領域、保険の種目
  coefficients.json  係数表
  industries.json    業種パック（10業種）
  chapters.json      レポートの章定義、執筆ルール、用語
src/js/     core / engine（算出）/ sample / charts（図）/ excel / report（紙面）/ prompts / ui
src/app.css スタイル（デザイン方針「検図」）
scripts/build.mjs   src/ を単一HTMLにまとめる
```

`src/` を直したら `node scripts/build.mjs` で `index.html` を作り直します。`npm i` の後に実行すると `index.offline.html` も作ります。

質問を足すときは `questions.json` に1行足します（アプリの「設定」画面からも足せます）。`fx` に「評価への反映方法」を書くと、コードを変えずに頻度や損害額へ反映されます。
